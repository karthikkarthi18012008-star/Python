
# Python Functions - Mini Utility Programs

## 📌 Concepts Covered

* Defining and calling user-defined functions
* Using function parameters and return values
* Conditional statements (`if`, `elif`, `else`)
* Temperature conversion (Celsius ↔ Fahrenheit)
* Password strength validation
* String methods (`lower()`, `replace()`)
* Built-in functions (`len()`, `any()`)
* Generator expressions
* Iterating through a list of dictionaries
* Calculating the total cost of items in a shopping cart
* Palindrome checking using string slicing (`[::-1]`)

## 📚 Learning Outcomes

* Create reusable functions for different tasks.
* Convert temperatures between Celsius and Fahrenheit.
* Validate passwords based on common security rules.
* Process lists of dictionaries to perform calculations.
* Use string manipulation techniques for data processing.
* Check whether a string is a palindrome efficiently.
* Improve problem-solving skills using Python functions.
